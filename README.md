# Сайт РИТМ — как выложить бесплатно

Это готовый сайт: обычные файлы HTML, CSS и JavaScript. Ничего собирать и устанавливать не нужно — достаточно загрузить файлы на хостинг.

## Что внутри

| Файл | Страница |
| --- | --- |
| `index.html` | Продающая главная: анимации, калькулятор честной цели, тарифы, вопросы |
| `login.html`, `signup.html`, `sandbox.html` | Вход, регистрация, ИИ-песочница |
| `pricing.html`, `checkout.html` | Тарифы и оформление |
| `home.html` | Личный кабинет автора |
| `wizard.html`, `rewards.html` | Мастер сбора: срок и цель, награды |
| `campaign.html`, `purchase.html` | Сбор: обзор, деньги и закупка |
| `metronome.html`, `cashgap.html`, `chat.html` | Метроном: финансы, кассовый разрыв, ИИ-чат |
| `rating.html` | Рейтинг доверия |
| `sbor.html`, `pay.html` | Публичная страница сбора и оплата бэкера |
| `404.html` | Страница «не найдено» |
| `assets/config.js` | Настройки: ссылка на форму пилота (необязательно) |

Кабинет — демо на вымышленных данных автора Алины: регистрации, аккаунтов и оплат нет. Сверху каждой страницы кабинета это написано.

## Публикация на GitHub Pages (бесплатно, 10 минут)

1. Зарегистрируйтесь на [github.com](https://github.com). Логин станет частью адреса сайта.
2. Нажмите **New repository** (плюсик вверху справа → New repository). Название — например, `ritm`. Выберите **Public** и нажмите **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Откройте папку `ritm-site` и перетащите в окно браузера **всё её содержимое** — файлы и папку `assets`, но не саму папку `ritm-site`. Файл `index.html` должен оказаться в корне репозитория.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
7. Через 1–3 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ritm/`. Ссылка появится вверху страницы Settings → Pages.

Скрытый файл `.nojekyll` можно не загружать — сайт работает и без него.

## Форма «Записаться в пилот»

Пока ссылки на форму нет, кнопки «Записаться в пилот» скрыты. Чтобы их включить:

1. Создайте форму в [Яндекс Формах](https://forms.yandex.ru) или Google Формах: имя, телефон или Telegram, город, чем занимаетесь, что хотите купить и за сколько.
2. Скопируйте публичную ссылку на форму.
3. В репозитории откройте `assets/config.js`, нажмите карандаш (Edit) и вставьте ссылку в кавычки:
   `pilotFormUrl: 'https://forms.yandex.ru/...'`
4. Нажмите **Commit changes**. Через минуту кнопки появятся на главной и в кабинете.

## Как обновлять сайт

Загрузите изменённые файлы так же, через **Add file → Upload files**. Файлы с теми же именами заменятся. Небольшие правки текста можно делать прямо в браузере — карандашом в нужном файле.

## Свой домен и хостинг в России (позже, перед пилотом)

- **Свой домен на GitHub Pages:** купите домен (например, у reg.ru), укажите его в Settings → Pages → Custom domain и пропишите DNS-записи по подсказке GitHub.
- **Яндекс Cloud** надёжнее открывается из России: Object Storage со статическим хостингом, бесплатный SSL через Certificate Manager. На бесплатном лимите стоит 0 ₽ в месяц, платить нужно только за домен. Загружая файлы, указывайте тип: `.css` — `text/css`, `.js` — `application/javascript`, `.svg` — `image/svg+xml`, иначе стили не подхватятся.

## Ограничения демо

- Шрифты Inter и Manrope грузятся с Google Fonts. Если они недоступны, сайт покажет системный шрифт.
- Анимации при прокрутке работают во всех современных браузерах; в Firefox и старом Safari они запускаются через запасной скрипт.
- Чтобы принимать настоящие деньги, нужен банк-партнёр с номинальным счётом и юридическое заключение по 259-ФЗ. Без этого сайт остаётся витриной и демо.
